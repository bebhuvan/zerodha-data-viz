# No ten-year holding of the Sensex since 1997 has lost money

Yearly return from holding the Sensex for one to fifteen years, every start month from July 1997: worst, middle and best. One-year holds lost money 28.7% of the time; ten-year holds never did.

How to read this. Each bar is one holding period. It runs from the worst yearly return anyone got over that period to the best, with the middle marked. The longer the hold, the shorter the bar and the further it sits from a loss.

Annualised returns of the price index, so dividends (about 1% to 1.5% a year) are not counted. 233 ten-year windows; the latest started in November 2016.

Source: BSE via Yahoo Finance; Zerodha calculations
